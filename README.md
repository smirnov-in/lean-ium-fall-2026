Это репозиторий одноимённого [курса в НМУ](https://mccme.ru/ru/nmu/courses-of-nmu/osen-20262027/nmu_autumn2026_formal_verification/) осеннего семестра 2026-го года.

Семинары 1–7 используют только Lean и его стандартную библиотеку. Начиная с семинара 8

## Оценка за курс

Оценка складывается из трёх компонентов: домашних заданий (они приведены в конце каждого файла семинара), проекта по формализации и экзамена по теории (материалу лекций). Планируются устная презентация проектов и устный экзамен. Однако если желающих будет слишком много, защита и экзамен будут проводиться в письменном формате. Каждый из трёх компонентов оценивается по системе «зачтено / не зачтено». Домашние задания засчитываются, если успешно сдано не менее 75 % задач курса (порог может измениться). Итоговая оценка ставится следующим образом:
- зачтён 1 из 3 компонентов — «удовлетворительно»;
- зачтены 2 из 3 — «хорошо»;
- зачтены все 3 — «отлично».

Сдавать домашние задания можно любым удобным способом. Предпочтительный вариант для тех, кто умеет пользоваться `git`, — создать форк этого репозитория и добавить в нём свои решения.

### Проект по формализации

Проект заключается в формализации в Lean нетривиального математического результата — например, задачи или теоремы из этого или другого курса НМУ. Тему и объём работы желательно заранее согласовать.

Можно пользоваться [mathlib](https://github.com/leanprover-community/mathlib4) и другими библиотеками, но проект должен содержать собственную работу по формализации и не сводиться к простому применению готовой теоремы. Для зачёта нужен завершённый код, который проверяется Lean и не содержит `sorry` или дополнительных аксиом, подменяющих доказательства.

На устной презентации нужно рассказать о результате, показать основные части кода и обсудить трудности, возникшие при переходе от неформального доказательства к формальному. В письменном варианте эти пояснения нужно приложить к коду в виде комментариев или README.

Примеры возможных тем (расположены по возрастанию предполагаемого объёма формализации):

- Неприводимость над $\mathbb Q$ многочленов $\prod_{i=1}^n(x-a_i)-1$ и $\prod_{i=1}^n(x-a_i)^2+1$, где $n\ge1$, а $a_1,\ldots,a_n$ — попарно различные целые числа;

- Для любого конечного множества точек евклидовой плоскости, не лежащих на одной прямой, существует прямая, содержащая ровно две точки этого множества;

- Если непрерывная функция $f : [0,1] \to [0,1]$ имеет точку минимального периода $3$ (то есть $f(f(f(x)))=x$ и $f(x)\ne x$), то для каждого $n\ge1$ она имеет точку минимального периода $n$;

- Для любого непрерывного отображения $f:S^2\to\mathbb R^2$ существует точка $x\in S^2$, для которой $f(x)=f(-x)$;

- Если функция $f : \mathbb N \to \mathbb N$ представима в $\lambda_{\to}$ на нумералах Чёрча замкнутым термом типа $N_A \to N_A$, где $N_A := (A \to A) \to A \to A$, а $A$ — базовый тип, то $f$ — расширенный полином;

- Число простых связных неориентированных помеченных графов на $n$ вершинах с $n$ рёбрами асимптотически равно $\sqrt{\pi/8}\,n^{n-1/2}$ при $n\to\infty$.

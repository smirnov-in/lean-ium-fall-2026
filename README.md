# Формальная верификация в математике

Это репозиторий одноимённого [курса в НМУ](https://mccme.ru/ru/nmu/courses-of-nmu/osen-20262027/nmu_autumn2026_formal_verification/) осеннего семестра 2026-го года.

##  Локальная установка

Для начала следует установить VSCode и Lean, процесс описан [тут](https://lean-lang.org/install/).

### Графический метод установки

Простейший способ работы с репозиторием курса — добавить его прямо в  VSCode.
После установки Lean нажмите на квантор всеобщности в правом верхнем углу,

![forall](images/forall.png?raw=true "Квантор всеобщности")

и выберите  `Open Project...` -> `Download Project...`.

![download](images/download.png?raw=true "Download Project")


Вставьте url
```
https://github.com/smirnov-in/lean-ium-fall-2026
```

и выберите директориую, в которую вы хотите клонировать этот репозиторий.
После скачивания необходимых файлов, она откроется автоматически.


### Метод установки через командную строку

```bash
git clone https://github.com/smirnov-in/lean-ium-fall-2026
cd lean-ium-fall-2026
lake exe cache get
```

Теперь в VSCode можно открыть только что созданную директорию `lean-ium-fall-2026`.

## Обновление

Материалы курса обновляются постепенно.
Чтобы обновить состояние до последней версии нажмите `Ctrl+Shitf+P`, наберите в открывшейся строке "pull" и выберите вариант `Git: Pull`.

Альтернативно, в командной строке в директории проекта наберите `git pull` (её можно открыть, например, нажав `Ctrl+j` в VSCode).
